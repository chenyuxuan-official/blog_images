# 博客图床仓库

本仓库用于存放博客文章封面、截图、架构图等图片资源。

## 使用规范与说明

1. **存放目录**：图片统一放置在 `images/` 目录下。
2. **格式建议**：建议对图片进行压缩，并优先使用 WebP 格式。
3. **CDN 引用**：推荐通过 jsDelivr CDN 引用图片，示例地址：
   ```text
   https://cdn.jsdelivr.net/gh/chenyuxuan-official/blog_images@main/images/example.webp
   ```
4. **网络说明**：`raw.githubusercontent.com` 直链在部分网络环境下访问不稳定，建议优先使用 jsDelivr CDN。
